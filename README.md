# 📌 Project Overview

The rapid spread of misinformation and fake news across digital platforms has become a major global challenge.  
This project presents an advanced Fake News Detection System using **Hybrid Deep Learning Techniques** integrated with **Explainable AI (XAI)** for transparent and reliable predictions.

The system analyzes news content and predicts whether the news is:

- ✅ Real News
- ❌ Fake News

The project focuses on:
- High prediction accuracy
- Fast processing
- Explainable outputs
- Professional web deployment
- User-friendly interface

---

# 🎯 Objectives

- Detect fake news using Machine Learning and NLP techniques
- Improve prediction accuracy using hybrid models
- Provide explainable and interpretable AI outputs
- Build a production-level responsive web application
- Deploy the system using modern cloud infrastructure
